# Vision v1

Status: draft

Living document. One source per fact. Brainstorm lives in `docs/brainstorm/`, not here.

## Gist
handsfree is an MCP server for automating computers and desktop UIs. The model writes a macro (a list of ops, data only). The driver runs it: it executes the ops, checks conditions, and enforces policy, approvals and audit, because only the driver knows what its operations do. The model is called back only for decisions. No LLM needed inside the run.

## Wedge
Guarded, repeatable macros over existing or custom drivers. Not another general computer-use server.

## Principles
1. The driver owns its domain: ops, conditions, risk classification and enforcement. The MCP layer stays thin. Shared mechanism (modes, approvals, audit) comes from a common `policy` crate linked into each driver, not from a central gateway.
2. Add host functions, not languages.
3. Smallest walking skeleton first.

## Scope
* Rust workspace. MCP server via pmcp, thin adapter over plain library crates.
* One executable: MCP server and driver in one process. Out-of-process drivers over Driver RPC come later (v2).
* Mechanisms: sequence (priority, later), fsm, and decision tree.
* Expression language: CEL (`handsfree-cel/1`).
* Driver RPC: JSON-RPC 2.0, NDJSON on stdio.
* Drivers: `mock`, `atspi`, `chromium`, `terminal`, `vt100`, `mcp_wrapper` (spike first).
* Audit: local JSONL. Analysis is out of scope.
* Linux desktop priority for v1.

## Non-goals
FSM, rules, controller and timeline mechanisms. Windows and macOS drivers. Recording and replay. OPA/Rego. Hash-chained audit. Event subscriptions. Isolation sandboxes.
